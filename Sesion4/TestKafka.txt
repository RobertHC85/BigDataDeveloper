Creo topics:
-----------
docker exec -it kafka-1 bash -lc "kafka-topics --bootstrap-server kafka-1:29092 --create --topic demo-topic-sesion4 --partitions 3 --replication-factor 1"
docker exec -it kafka-1 bash -lc "kafka-topics --bootstrap-server kafka-1:29092 --describe --topic demo-topic-sesion4"

Listo topics:
------------
kafka-topics --bootstrap-server kafka-1:29092 --list

creamos un productor:
--------------------
docker exec -it kafka-1 bash -lc "kafka-console-producer --bootstrap-server kafka-1:29092 --topic demo-topic-sesion4"

creamos un consumidor:
---------------------
docker exec -it kafka-1 bash -lc "kafka-console-consumer --bootstrap-server kafka-1:29092 --topic demo-topic-sesion4 --from-beginning"

keys:
----
docker exec -it kafka-1 bash -lc "kafka-console-producer --bootstrap-server kafka-1:29092 --topic demo-topic-sesion4 --property parse.key=true --property key.separator=:"

user1:login
user2:login
user1:click
user2:click
user1:checkout

consumidor con offset:
docker exec -it kafka-1 bash -lc "kafka-console-consumer --bootstrap-server kafka-1:29092 --topic demo-topic-sesion4 --from-beginning --property print.offset=true --property print.partition=true --property print.key=true"

Crea un topic con 6 particiones:
-------------------------------
docker exec -it kafka-1 bash -lc \
"kafka-topics --bootstrap-server kafka-1:29092 --create --topic orders --partitions 6 --replication-factor 1"

consumer en el grupo cg-orders (Terminal A):
-------------------------------------------
docker exec -it kafka-1 bash -lc \
"kafka-console-consumer --bootstrap-server kafka-1:29092 --topic orders --group cg-orders --property print.key=true --property print.partition=true"

2do consumer en el mismo grupo (Terminal B):
-------------------------------------------
docker exec -it kafka-1 bash -lc \
"kafka-console-consumer --bootstrap-server kafka-1:29092 --topic orders --group cg-orders --property print.key=true --property print.partition=true"
